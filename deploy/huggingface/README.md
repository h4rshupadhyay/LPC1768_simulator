# LPC1768 Simulator

Browser simulator for the ALS LPC1768 kit: compile Embedded C, run it on an emulated
Cortex-M3, and build circuits with external parts on the 3D Workbench.

Source: https://github.com/KavyPings/LPC1768_simulator_extended

Every visitor gets their own simulator. Compilation is restricted to the project's
headers and the C library.
